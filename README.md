# 🍽️ Swiggy Sales Analysis Dashboard | Excel

## 📊 Project Overview

This project is an **interactive Swiggy Sales Analysis Dashboard** created using Microsoft Excel. The objective of this project is to analyze sales performance, customer ratings, order trends, food categories, and state-wise performance using interactive dashboards and data visualization.

The project transforms raw Swiggy order data into meaningful business insights through **Pivot Tables, Pivot Charts, Slicers, KPI Cards, and interactive visualizations**.

---

## 🎯 Project Objectives

* Analyze overall sales and order performance.
* Identify monthly, weekly, daily, and quarterly sales trends.
* Analyze sales performance across different states and cities.
* Compare Veg and Non-Veg sales.
* Analyze customer ratings and rating counts.
* Identify top-performing cities based on sales.
* Provide an interactive dashboard for business performance analysis.

## 📈 Dashboard Analysis

### 1. Monthly Sales Trend

Analyzed sales performance across different months to identify fluctuations and peak sales periods.

### 2. Daily Sales Trend

Compared sales performance across different days of the week.

### 3. Weekly Sales Trend

Analyzed sales patterns across different weeks.

### 4. Quarterly Analysis

Compared Q1, Q2, and Q3 based on:

* Sales
* Average Rating
* Number of Orders

### 5. Sales by Food Type

Compared **Veg and Non-Veg** sales contribution.

### 6. Sales by State

Used a geographical map to visualize sales performance across Indian states.

### 7. Top 5 Cities by Sales

Identified the top-performing cities based on total sales.

### 8. Interactive Filters

The dashboard includes interactive slicers for:

* Month
* State
* Category
* Restaurant Name

These filters allow users to explore the data dynamically.

## 💡 Key Insights

* Total sales generated were approximately **₹53.01M**.
* The average customer rating was **4.34**.
* Total orders were approximately **197.43K**.
* The average order value was approximately **₹268.51**.
* **Q2** generated the highest sales among the analyzed quarters.
* **Bengaluru** was among the top-performing cities by sales.
* Veg food contributed a larger share of sales compared with Non-Veg food.
* The dashboard provides a clear view of sales performance across different states, cities, categories, and time periods.
